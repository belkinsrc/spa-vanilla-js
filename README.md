# Проект Social Network - это простая социальная сеть, которая имитирует функционал обмена постами, комментариями и взаимодействиями между пользователями
### [Посмотреть сайт](https://social-network-project.ru)

Проект включает две основные страницы: список постов, где можно перейти на профиль автора поста, и страницу пользователей, где можно просматривать посты и комментарии каждого пользователя. Это замкнутая система, позволяющая свободно перемещаться между постами, комментариями и пользователями.

## Технологии

В этом проекте использованы следующие технологии:

+ **WEB Components** - технология, которая позволяет создавать на чистом JavaScript многократно используемые компоненты в веб-приложениях
+ **Node.js** - для написания серверной логики
+ **Express.js** - для создания веб-сервера и написания серверной логики
+ **Vite** - для предоставления dev-сервера в режиме разработки и сборки бандла в production режиме.
+ **MongoDB** - для хранения данных приложения
+ **Mongoose.js** - для более удобного взаимодействия с MongoDB
+ **Nginx** - веб-сервер и прокси-сервер
+ **Docker** - платформа для контейнеризации и развертывания приложений

#### Для запуска приложения НЕОБХОДИМ локально установленый Docker

- `https://www.docker.com/products/docker-desktop/`

#### Проект запускается на портах 5173, 5001 - убедитесь, что порты не заняты

- `localhost:5173`

## Установка и запуск проекта

1. Клонируйте репозиторий на свой компьютер:
    ```shell
    git clone https://github.com/belkinsrc/spa-vanilla-js.git
    ```
2. Перейдите в папку проекта:
    ```shell
    cd  spa-vanilla-js
    ```
3. Запустите проект внутри контейнерах Docker (прежде установленым локально):
    ```shell
    docker-compose -f docker-compose.dev.yml up -d
    ```
4. Откройте в браузере страницу http://localhost:5173 для просмотра проекта.
